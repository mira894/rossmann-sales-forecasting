# rossmann-sales-forecasting


# Rossmann Sales Forecasting – Business Intelligence and Advance Data Management Assignment

## Project Overview
This project presents a predictive analytics solution to forecast daily sales for Rossmann retail stores. It follows a complete data science lifecycle including data preprocessing, exploratory data analysis, feature engineering, model development, optimization, and evaluation. The project is implemented in Python using Jupyter notebooks.

---

## Folder Structure
```
rossmann-sales-forecasting/
│
├── data/
│   ├── raw/                 # Original Kaggle CSV files
│   ├── processed/           # Cleaned and merged datasets
│
├── notebooks/
│   ├── 01_data_preprocessing.ipynb
│   ├── 02_eda.ipynb
│   ├── 03_feature_engineering.ipynb
│   ├── 04_modeling.ipynb
│   ├── 05_evaluation_insights.ipynb

```

---

## System Requirements
- Operating System: Windows / macOS / Linux
- Python version: Python 3.10 or higher
- Internet connection (only required once for package installation)

---

## Step 1: Install Python
1. Download Python from: https://www.python.org/downloads/
2. During installation, check “Add Python to PATH”
3. Verify installation:
   ```
   python --version
   ```

---

## Step 2: Set Up Virtual Environment (Recommended)
From the project root directory:

```
python -m venv venv
```

Activate the environment:

**Windows**
```
venv\Scripts\activate
```

**macOS / Linux**
```
source venv/bin/activate
```

---

## Step 3: Install Required Libraries
```
pip install -r requirements.txt
```

---

## Step 4: Launch Jupyter Notebook
```
jupyter notebook
```

---

## Step 5: Run the Project (Important Order)
Run notebooks in the following sequence using **Kernel → Restart & Run All**:

1. 01_data_preprocessing.ipynb
2. 02_eda.ipynb
3. 03_feature_engineering.ipynb
4. 04_modeling.ipynb
5. 05_evaluation_insights.ipynb

---
